# Custom ELB

An electronic lab notebook application, with macOS as the initial primary platform.

## Project status

This repository is the starting point for the application. Implementation has not
started, and the technology stack has not yet been selected.

## Initial direction

- Build a practical electronic lab notebook for day-to-day laboratory work.
- Prioritize the Mac experience in the first release.
- Define notebook workflows, data storage, and backup requirements before implementation.

## Development

Setup, build, and test instructions will be added as the application takes shape.
Do not commit credentials, private laboratory records, or local notebook data to
this public repository. Use synthetic data for examples and test fixtures.
